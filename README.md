# 🧽 Фан-сайт «Welcome to the World of Nickelodeon!»

Односторінковий сайт про мультсеріали Nickelodeon з реєстрацією, входом і коментарями.

## 📁 Що де лежить

```
nick-fan-site/
├── public/                  ← ФРОНТЕНД (те, що бачить користувач)
│   ├── index.html           ← весь текст і структура сторінки
│   ├── style.css            ← кольори, розміри, вигляд
│   └── script.js            ← перемикання сторінок, вхід, коментарі
├── netlify/functions/
│   └── api.mjs              ← БЕКЕНД (реєстрація, вхід, коментарі)
├── netlify.toml             ← налаштування для Netlify
├── package.json             ← список бібліотек
└── .gitignore               ← що не завантажувати на GitHub
```

**Як це працює:** браузер показує `index.html`. Коли людина реєструється або пише
коментар, `script.js` надсилає запит на адресу `/api/...`. Netlify запускає файл
`api.mjs`, а той зберігає дані в **Netlify Blobs** (безкоштовному сховищі Netlify).
Окремий сервер не потрібен.

## 🛠 Крок 1. Підготовка (один раз)

1. Встановіть **Node.js** (версію LTS): https://nodejs.org
2. Встановіть **Git**: https://git-scm.com
3. Створіть акаунти на **GitHub** (https://github.com) і **Netlify** (https://netlify.com).
   На Netlify можна просто увійти через GitHub.
4. Відкрийте папку `nick-fan-site` у VS Code (File → Open Folder).
5. Відкрийте термінал у VS Code (Terminal → New Terminal) і виконайте:

```bash
npm install
npm install -g netlify-cli
```

## 💻 Крок 2. Запуск на своєму комп'ютері

```bash
netlify dev
```

Відкрийте http://localhost:8888. Тут працює все, разом із реєстрацією та коментарями.
Зупинити: `Ctrl + C` у терміналі.

> ⚠️ Якщо просто відкрити `index.html` подвійним кліком або через Live Server,
> сайт буде видно, але вхід і коментарі **не працюватимуть**, бо бекенд запускає лише `netlify dev`.

## 🚀 Крок 3. Публікація на Netlify (через GitHub)

1. На GitHub створіть новий репозиторій (кнопка **New**), наприклад `nick-fan-site`.
2. У терміналі VS Code виконайте (замініть `ВАШ-ЛОГІН`):

```bash
git init
git add .
git commit -m "Перша версія сайту"
git branch -M main
git remote add origin https://github.com/ВАШ-ЛОГІН/nick-fan-site.git
git push -u origin main
```

3. На Netlify натисніть **Add new site → Import an existing project → GitHub**
   і виберіть свій репозиторій. Налаштування підтягнуться з `netlify.toml`,
   тому просто натисніть **Deploy**.
4. Через хвилину сайт буде доступний за адресою на зразок `https://назва.netlify.app`.

Після цього **кожен `git push`** автоматично оновлює сайт.

> ⚠️ Не використовуйте «перетягування папки» (Netlify Drop): так завантажуються
> лише HTML/CSS/JS, а бекенд (`netlify/functions`) не запуститься.

## ✏️ Як щось змінити

| Хочу змінити…              | Файл                     |
|----------------------------|--------------------------|
| Текст, додати мультсеріал  | `public/index.html`      |
| Кольори, шрифти, розміри   | `public/style.css` (змінні на початку файлу) |
| Поведінку кнопок           | `public/script.js`       |
| Правила реєстрації         | `netlify/functions/api.mjs` |

**Додати п'ятий мультсеріал:**
1. В `index.html` скопіюйте один `<section id="..." class="page hidden" data-show="...">` і змініть `id` та `data-show` (наприклад, `avatar`).
2. Додайте блок у праву панель: `<a href="#avatar" class="show-block ...">`.
3. В `api.mjs` допишіть `"avatar"` у список `SHOWS`.

## 🔐 Безпека (що вже зроблено)

- Паролі зберігаються лише як **хеш** (bcrypt), а не у відкритому вигляді.
- Коментарі виводяться через `textContent`, тому ніхто не вставить на сторінку шкідливий код.
- Видаляти можна лише власні коментарі.
